## 2023-10-27 - Focus States and ARIA Labels in Native Elements
**Learning:** While the app has a `Button` UI component, layout components like `Header` and `Sidebar` frequently bypass this and use native HTML `<button>` and `<input>` elements. This requires manual implementation of standard accessibility features like `aria-label`s and focus indicators on these specific components. The standard focus state convention here uses Tailwind utility classes: `outline-none focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[var(--accent)]`.
**Action:** When working on layout files, always verify that interactive native elements include proper ARIA labels (in Spanish) and manually apply the standard `focus-visible` utility classes, rather than assuming a global UI component is handling it.
