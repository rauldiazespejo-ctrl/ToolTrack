## 2026-08-17 - Manual Accessibility in Layout Components
**Learning:** Layout components like Header and Sidebar in this app frequently bypass global UI abstractions (like `<Button>`) and use native HTML elements (`<button>`, `<input>`) directly. This means standard accessibility features (like `aria-label`s for icon buttons) and the global focus-visible styling conventions must be applied manually to these elements to ensure keyboard usability and screen reader support.
**Action:** Always check native `<button>` and `<input>` elements in layout or custom component structures to ensure they include explicit `aria-label`s if they only contain icons, and manually apply the project's standard focus state classes: `outline-none focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[var(--accent)]`.
