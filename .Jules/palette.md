## 2025-01-20 - Layout Components Bypass Global UI Abstractions
**Learning:** Layout components (like `Header` and `Sidebar`) frequently bypass global UI abstractions (`<Button>`, `<Input>`) and use raw HTML elements (`<button>`, `<input>`).
**Action:** When working on layout components, always remember to manually implement `aria-label`s and the standard focus-visible utility classes (`outline-none focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[var(--accent)]`) to ensure keyboard accessibility and screen reader support, since they don't inherit these from standard UI components.
