## 2024-08-02 - Layout components missing standard UI abstractions\n**Learning:** The layout components (Header, Sidebar) bypass the global UI abstractions like `<Button>` and use native HTML elements. As a result, they were missing standard accessibility features like `aria-label` and focus styles.\n**Action:** Manually add `aria-label` (in Spanish) and the standard focus-visible utility classes to these elements to ensure keyboard accessibility and proper screen reader support.
