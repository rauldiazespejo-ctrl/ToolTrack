## 2025-01-20 - Layout Component Accessibility Defaults
**Learning:** Layout components (like `Header` and `Sidebar`) in this app frequently bypass the global `<Button>` and `<Input>` wrappers in favor of native HTML `<button>` and `<input>` elements for granular styling control. This leads to a persistent pattern where these controls lack the default ARIA labels and focus-visible states typically provided by the design system, rendering icon-only buttons highly inaccessible.
**Action:** When auditing layout files or navigation menus, explicitly check for native HTML form controls and ensure they manually implement `aria-label`s and the standard focus ring utility classes (`outline-none focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[var(--accent)]`).
