## 2026-08-24 - Layout Component Accessibility
**Learning:** Layout components in this app (like Header and Sidebar) frequently bypass global UI abstractions like `<Button>` and use native HTML `<button>` and `<input>` elements.
**Action:** Manually implement `aria-label`s (in Spanish) and the standard focus-visible utility classes (`outline-none focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[var(--accent)]`) on these native elements to ensure accessibility.
