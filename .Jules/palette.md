## 2024-10-06 - Layout Component Accessibility
**Learning:** Layout components in this application (like `Header` and `Sidebar`) frequently bypass global UI abstractions like `<Button>` and use native HTML `<button>` and `<input>` elements. Because of this, they are prone to missing essential accessibility attributes like `aria-label` for icon-only buttons and the standard focus state conventions.
**Action:** When working with layout components or components not utilizing the shared `<Button>`/`<Input>` abstractions, manually verify and implement `aria-label`s for non-text interactive elements, and ensure the standard focus-visible utility classes (`outline-none focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[var(--accent)]`) are explicitly added to ensure keyboard accessibility.
