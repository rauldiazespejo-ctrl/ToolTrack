## 2024-05-18 - Missing Accessibility Attributes in Layout Components
**Learning:** Layout components (like Header and Sidebar) frequently bypass global UI abstractions like `<Button>` and use native HTML `<button>` and `<input>` elements. Because of this, they miss the default ARIA labels and focus states provided by the global components.
**Action:** When working with layout components, manually implement `aria-label`s and the standard focus-visible utility classes (`outline-none focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[var(--accent)]`) to ensure accessibility is maintained across the entire application interface.
